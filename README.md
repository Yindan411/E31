## 模型怎么跑

```matlab
cd('E:\TCS_demo\TCS_答辩资料\model')
tcs4_demo        % 一键：建模(如无) + 打开模型窗口 + 跑14工况 + 出8张图
```

只想改参数重跑（不重建模型）：

```matlab
p = tcs4_params('mu_road',0.5);    % 例：改成湿地
assignin('base','p',p);
sim('TCS4_Top');
```

**截图建议**（模型所有模块中文命名，每个子系统内有中文公式注释）：
① 顶层全景 → ② 双击 `TCS_控制器` → ③ `3_介入退出判断`（滞环状态机） → ④ `6a_PID扭矩补偿_前轴`（P/I/D 分开搭 + 抗饱和） → ⑤ `5a` vs `5b` 油门×转速查表（前后轴曲线对比） → ⑥ `2_滑移率计算`。
布局若乱：在 Simulink 里打开子系统 → Ctrl+A 全选 → 工具条"自动排列"。

## 模型里有什么（对照你的需求清单）

| 需求 | 实现位置 |
|---|---|
| TCS 介入与退出 | `3_介入退出判断`（0.18/0.05 滞环 + 车速门限）+ `4_介入平滑` |
| 扭矩补偿 | `6a/6b_PID扭矩补偿`（前后轴各一路，条件积分抗饱和） |
| 油门×转速扭矩查表 | `5a/5b`（2-D 查表：油门开度 × 车轮转速 → 单电机扭矩） |
| 前后轴不同查表曲线 | 减速比 11.8/13.2 导致断点不同，两条曲线物理上天然错开 |
| 滑移率计算 | `2_滑移率计算`（四轮独立计算 + 低通 + 前/后/整车取大） |
| 输入：参考车速 + 四轮转速 | 控制器输入端口；参考车速来源可切换（真值 / 四轮取小估计） |
| 四轮转速 | `VEH_被控对象` 里四个独立车轮模型（各自轮胎/惯量/载荷） |

## 关键结果（详见 `model/sim_out/metrics.txt`）

| 工况 | TCS OFF 滑移率峰值 | TCS ON 滑移率峰值 | 8s 末速变化 |
|---|---|---|---|
| 干地 μ=1.4 | 3.17 | **0.66** | 持平（干地本就接近抓地极限） |
| 湿地 μ=0.5 | 12.6（车轮空转） | **1.26** | **+24.5 km/h**（66.7 → 91.2） |
| μ 1.0→0.45 阶跃 | — | 0.68，1s 内恢复 | 稳定 |
| 质量扫描 210~290kg | — | 峰值变化 <0.06 | 鲁棒 |

## 答辩前必做三件事

1. **改易拉宝**：0.2→0.18、0.15→0.12（见 doc 06，有现成替换稿）；
2. **背熟** doc 02 的第 4 问（参考车速）、第 8 问（实车测试）——这两个必被问；
3. 如果赛前有 2 周：执行 doc 02 第 8 问的采集方案里 **D3-6（台架 + 滑行测试）**——零风险、一两天、能拿到第一批真数据，"real data"打分项就从 0 变非 0。
