# 04 · 算法与参数详解（对应 `tcs4_params.m`，逐条可背）

> 单位约定：N · m · s · rad/s · rpm · kg。
> 所有参数集中在 `model/tcs4_params.m`，模型模块里只写 `p.xxx`——"改参数不改模型"是可维护性设计，答辩时可以主动提。

---

## 1. 整车与轮胎参数

| 参数 | 值 | 物理含义 | 来源/依据 |
|---|---|---|---|
| `m` | 250 kg | 整车质量含车手 | 车队实测（车重+车手） |
| `L, a_cg, b_cg` | 1.565 / 0.845 / 0.720 m | 轴距、质心到前/后轴距离 | 整车称重配平 |
| `h_cg` | 0.30 m | 质心高 | 结构测量估计 |
| `CdA` | 1.00 m² | 风阻系数×迎风面积 | 同类 FSAE 赛车典型值 |
| `f_rr` | 0.015 | 滚动阻力系数 | 光滑沥青典型值（滑行测试可标定） |
| `r_w` | 0.198 m | 轮胎滚动半径 | Hoosier 16x7.5-10 规格计算 |
| `B_pac, C_pac` | 10.75 / 1.65 | 魔术公式刚度/形状因子 | 决定 μ-λ 曲线形状，文献值 |
| **派生 `lam_p`** | **0.13** | **峰值滑移率** = tan(π/2C)/B | 公式自动算出，是目标滑移率的依据 |

**μ-λ 曲线**：μ(λ) = sin(C·atan(B·λ))。λ=0 时 μ=0；λ=0.13 时 μ 达峰值 ≈1.0；之后下降（深滑移区附着变差）。**这条曲线是整个 TCS 的物理基础**：目标滑移率必须取在峰值左侧（稳定分支），右侧是负刚度区，开环就不稳定。

**答辩讲法**："我们不需要精确的轮胎模型也能设计控制器——因为控制目标定在稳定分支上，控制器对轮胎参数误差是鲁棒的（质量扫描证明了这一点）。"

## 2. 电机与传动

| 参数 | 值 | 说明 |
|---|---|---|
| `T_mot_max` | 21 N·m | AMK DD5 峰值扭矩（4 台合计轮端 4×21×13.2×0.89 ≈ 987 N·m 后轴） |
| `n_base / n_max` | 9100 / 18600 rpm | 基速/最高转速：基速前恒扭矩，之后恒功率降扭 |
| `T_at_maxn` | 10.3 N·m | 最高转速处扭矩（恒功率段终点） |
| `i_f / i_r` | 11.8 / 13.2 | 前/后轴减速比 → **前后查表曲线不同的物理原因** |
| `eta_drv` | 0.89 | 电机效率 0.92 × 减速器 0.97 |

**油门×转速查表（2-D）**：`T_map = 油门开度(5档) × 电机外特性(4断点)`。横轴用**车轮转速**而非电机转速，于是同一张表在不同减速比下自然形成两条不同的前/后曲线——后轴（i=13.2）同车速下电机转速更高、更早进恒功率降扭区。这是"前后轴不同开度查表曲线"的物理解释（不是人为造两条表）。

## 3. TCS 控制参数（答辩必背的 6 个）

| 参数 | 值 | 为什么是这个值 |
|---|---|---|
| `lam_ref` | **0.12** | 峰值 0.13 的稳定侧。附着力损失 <1%，换取闭环稳定裕度 |
| `lam_on` | **0.18** | 介入阈值 = 目标值 + 0.06：给滤波延迟和信号噪声留死区，避免频繁误触发 |
| `lam_off` | **0.05** | 退出阈值远低于介入阈值 → **滞环**。0.18/0.05 之间的区间宽 0.13，一个控制周期（20ms）内轮速变化跨不过去，杜绝"开关振荡" |
| `v_min` | 0.15 m/s | 低速门限：静止/挪车时不介入（轮速信号在低速不可信，且低速无需 TCS） |
| `Kp / Ki / Kd` | **20 / 20 / 0** | 见下方调参段 |
| `Ts` | 0.02 s | 与 VCU/CAN 节拍一致 |

**PID 三个增益的来历（fig6 数据支撑）**：
- `Kp=20`：滑移率误差 0.1 → 补偿 2 N·m。Kp=5 时峰值滑移率 1.44（太慢），Kp=100 时虽然峰值最低（0.28）但 RMS 反而劣化且接近稳定边界——取 20；
- `Ki=20`：消除稳态误差（P 控制稳态滑移率偏 0.9，PI 后 0.026，metrics 里有对比）；
- `Kd=0`：**故意不用**。轮速信号有齿盘量化噪声，微分会放大噪声；且 P/I 已够快。被问"为什么不用 D"是送分题："不是不会用，是信噪比不允许，工程上 D 项加了低通才有意义，而我们实测 P/I 裕量充足。"

## 4. 滤波与平滑时间常数（5 个 τ，各自的物理对应物）

| 参数 | 值 | 对应的真实物理 |
|---|---|---|
| `tau_slip` | 0.03 s | 滑移率低通：滤轮速噪声（齿盘量化 + CAN 量化） |
| `tau_ref` | 0.05 s | 参考车速低通：估计值的平滑 |
| `tau_en` | 0.04 s | 介入/退出 0-1 跳变 → 连续过渡，防补偿扭矩阶跃 |
| `tau_tq` | 0.03 s | 扭矩指令一阶平滑 ≈ 电机扭矩响应时间（AMK 约 30ms） |
| `tau_relax` | 0.04 s | 轮胎滑移松弛：轮胎力不是瞬间建立的（轮胎"松弛长度"现象） |

**统一讲法**："每个 τ 都对应一个真实的物理延迟，不是调出来的美化参数。τ 太小→噪声进环路；τ 太大→介入滞后。我们用仿真确认了当前组合下介入延迟约 200ms、无振荡。"

**一阶低通离散实现**（模型里的 Discrete Filter）：`y[k] = (1−α)y[k−1] + α·u[k−1]`，其中 `α = Ts/(τ+Ts)`。被问"怎么实现的"就写这个式子。

## 5. 抗饱和与安全限幅

| 机制 | 实现 | 为什么需要 |
|---|---|---|
| **条件积分抗饱和（Clamping）** | 输出已饱和 且 误差与输出同号 → 冻结积分器 | 深滑移时补偿顶在限幅上，积分器若继续累积，滑移率回落后会严重过冲（车"顿挫"） |
| **补偿限幅 = 车手扭矩 × `comp_ratio`** | 动态 Saturation，上下限 = ±T_drv | TCS 只能减扭矩：**任何算法故障的后果上限 = 车手松油门**，不会对抗车手 |
| **扭矩变化率限制 `tq_rate`=200 N·m/s** | Rate Limiter | 防扭矩突变激励传动系统振荡 + 单帧 CAN 丢失不产生扭矩跳变 |
| **介入复位积分** | 介入上升沿复位积分器 | 每次介入从零开始，不带历史包袱 |

## 6. 参考车速估计（`speed_ref_mode`）

- **模式 2（默认）**：直接使用输入的参考车速——对应"系统给定参考车速"的接口定义（用户需求）；
- **模式 1**：四轮取小 × r_w + 低通——无 GPS 时的实车替代方案；
- 两种模式跑同一工况对比（fig8）：控制效果几乎无差（峰值 0.662 vs 0.664）——说明当前估计方案在 TCS 闭环工作时不构成瓶颈。

**为什么"取小"而不是"取平均"**：平均会把打滑轮的虚假轮速混进来抬高估计；取小在加速工况下天然偏向"最不滑的轮子"。制动工况要改成"取大"（对称逻辑），这是实车标定项。

## 7. 被控对象建模假设（诚实清单）

| 简化 | 现实 | 影响 |
|---|---|---|
| 纵向单自由度车身（无横摆/侧倾） | 弯道中载荷左右转移 | 直线加速结论不受影响；弯道 TCS 是下一步 |
| 轮胎μ-λ 纯滑移模型（无侧偏联合） | 联合工况 | 同上 |
| 轴荷转移用上一拍加速度 | 准静态 | 断开代数环，误差一拍（0.5ms），可忽略 |
| 电机恒功率段线性化查表 | 实际有电流限幅细节 | 外特性表来自说明书，误差小 |

**讲法**："仿真的目的不是复现世界，是验证控制律的结构和参数趋势——这些简化不改变结论方向，我们列出来是让大家知道结论的适用边界。"
